WEB CON MÚSICA CONTINUA

Esta versión elimina el botón de activar música e intenta reproducir
la canción automáticamente al abrir index.html.

IMPORTANTE:
Los navegadores modernos suelen bloquear la reproducción automática
con sonido. Si el navegador la bloquea, no existe una forma fiable de
obligarlo mediante HTML/CSS/JavaScript sin una interacción del usuario.

La navegación entre apartados no recarga la página, por lo que cuando
la música está sonando continúa sin cortarse ni reiniciarse.

PARA AÑADIR LA CANCIÓN:
1. Pon un archivo MP3 al lado de index.html.
2. Llámalo exactamente musica.mp3.
3. Abre index.html.

Si el navegador bloquea el sonido, tendrás que iniciar la reproducción
desde los controles del propio navegador o permitir el audio para esa
página.
